# Hermes Autopilot: prompts to hand your agent

copy-pasteable prompts that only make sense inside an agent: they lean on memory, skills, session history, the terminal. each one is safe by default, it shows you the result and changes nothing until you say yes, and each ran on a real Hermes Agent box before it was posted.

each page is the prompt as posted. newest first.

## how to use one

1. open a fresh Hermes Agent chat (terminal, Desktop, or your gateway channel).
2. paste the whole prompt, tags included.
3. answer what it asks. it stops and waits before anything is written.
