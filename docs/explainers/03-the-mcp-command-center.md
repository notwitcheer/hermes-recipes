# release explainer #3: the MCP command center

posted 2026-09-02. original: [https://x.com/witcheer/status/2095063178778427564](https://x.com/witcheer/status/2095063178778427564)

managing MCP servers in Hermes Agent is now super user friendly and easy to do.

this new release added one desktop page where your servers and the whole catalog live together.

what it does for you:

(1) adding a server is a paste. drop in what you have and the page imports it.

(2) background health checks watch every server and nudge you to re-auth when needed.

(3) a cost overlay shows what each server's tool schemas cost you in tokens, plus 30 days of usage per server.

(4) hermes:// deep links install a server in one click, always behind an explicit confirmation.

everything can be managed through the new dashboard!
