# Hermes Wingtips #113: switch projects from the chat

posted 2026-10-29. original: [https://x.com/witcheer/status/2115817431616598488](https://x.com/witcheer/status/2115817431616598488)

a project in Hermes Agent is a named workspace that can hold several folders, say an API repo and a WEB repo for one app.

in Hermes Desktop you can move a chat into one by asking:

`switch this chat to my Recipe Box project`

Hermes finds it by name and moves the chat's workspace to the project's primary folder. ask which projects you have and it lists them, with the one this chat is in.

nice when one chat turns into work on another app, or when you hop between a side project and the day job!

docs: [https://hermes-agent.nousresearch.com/docs/reference/tools-reference](https://hermes-agent.nousresearch.com/docs/reference/tools-reference)
