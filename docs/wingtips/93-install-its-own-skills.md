# Hermes Wingtips #93: let your Hermes Agent install its own skills

posted 2026-10-06. original: [https://x.com/witcheer/status/2107371954009247994](https://x.com/witcheer/status/2107371954009247994)

your Hermes Agent can find a skill and run the install itself, so you don't need the skill's name or the command. ask in plain words:

"find a skill for flashcards and install it."

it picks a match, runs the security scan and then tells you what to say to use the new skill.

handy when you want your agent to pick up something new, or when you're setting up a fresh profile!

it knows how because every Hermes Agent ships with a built-in skill called hermes-agent, which covers how Hermes works and how to configure it.

docs: [https://hermes-agent.nousresearch.com/docs/user-guide/features/skills](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills)
