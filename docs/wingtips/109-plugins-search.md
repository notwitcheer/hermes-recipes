# Hermes Wingtips #109: hermes plugins search

posted 2026-10-24. original: [https://x.com/witcheer/status/2113910871046947127](https://x.com/witcheer/status/2113910871046947127)

the Hermes plugin catalog is a reviewed list of plugins you can install by name. you can search it from your terminal:

`hermes plugins search <term>`

type a word like weather, rss or telegram. Hermes matches it against plugin names, descriptions and the tools each plugin adds, and the results end with the install line. the install then asks if you want the plugin on straight away.

great when you want weather tools for your agent, an RSS reader in Hermes Desktop or a new memory provider!

docs: [https://hermes-agent.nousresearch.com/docs/user-guide/features/plugins](https://hermes-agent.nousresearch.com/docs/user-guide/features/plugins)
