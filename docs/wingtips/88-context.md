# Hermes Wingtips #88: /context, see what fills your model's context window, by category, with the free space left

posted 2026-10-01. original: [https://x.com/witcheer/status/2105552884670550343](https://x.com/witcheer/status/2105552884670550343)

your Hermes Agent's context window holds more than your messages: the system prompt, the tool definitions, your memory, any project rules and the conversation so far.

how much room does each one take?

type this in the chat:

`/context`

you get a breakdown of the window by what fills it, with the free space that is left.

useful before a long session, or when you want to see how close a chat is to compressing!

docs: [https://hermes-agent.nousresearch.com/docs/reference/slash-commands](https://hermes-agent.nousresearch.com/docs/reference/slash-commands)
