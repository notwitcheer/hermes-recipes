# Hermes Wingtips #89: /branch, copy the conversation into a new session and try another direction, the original kept

posted 2026-10-02. original: [https://x.com/witcheer/status/2105922267636965538](https://x.com/witcheer/status/2105922267636965538)

it copies your conversation with your Hermes Agent into a new session, history included, and you carry on in the copy.

want to try a different idea without losing where you are?

type this in the chat:

`/branch`

useful before a big change of direction, or to compare two answers from the same starting point!

name the branch if you like: `/branch plan-b`. without a name it takes the original title with a number.

docs: [https://hermes-agent.nousresearch.com/docs/reference/slash-commands](https://hermes-agent.nousresearch.com/docs/reference/slash-commands)
