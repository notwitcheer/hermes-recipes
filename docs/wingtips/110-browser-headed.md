# Hermes Wingtips #110: browser.headed

posted 2026-10-27. original: [https://x.com/witcheer/status/2115013131865117001](https://x.com/witcheer/status/2115013131865117001)

Hermes Agent's local browser runs in the background by default. one setting opens it as a Chromium window on your screen:

`hermes config set browser.headed true`

you see every page and click as the agent works. the window also stays open between turns, so you can sign in or clear a CAPTCHA yourself, and your login stays warm across the conversation.

great for watching a new task run the first time, a site that asks you to sign in or a demo for a friend!

docs: [https://hermes-agent.nousresearch.com/docs/user-guide/features/browser](https://hermes-agent.nousresearch.com/docs/user-guide/features/browser)
