Hermes Wingtips #31: see what every message costs before you send it

`hermes prompt-size`

it prints the fixed budget of a fresh session: the full system prompt, the skills index, your MEMORY.md and USER.md snapshots, the prompt tiers, and the JSON schemas for every enabled tool.

if you want to manage it:

- `hermes tools` turns off toolsets you never use 
- `hermes skills` uninstalls what you don't need
- AGENTS.md in your working directory count towards the total too
