# Hermes Wingtips #94: attach a file to your message

posted 2026-10-07. original: [https://x.com/witcheer/status/2107731405987856566](https://x.com/witcheer/status/2107731405987856566)

your Hermes Agent can take a whole file as part of your message, with no copy and paste.

type @, pick file: from the menu, then add the file's name and your question:

`@file:meeting-notes.md turn this into a to-do list`

handy for meeting notes, or a config file you want checked!

on X the line carries a space after the @ so it doesn't tag an account. type it with no space.

only part of a file? add the line numbers after the name: `@file:meeting-notes.md:3-5` sends lines 3 to 5.

docs: [https://hermes-agent.nousresearch.com/docs/user-guide/features/context-references](https://hermes-agent.nousresearch.com/docs/user-guide/features/context-references)
