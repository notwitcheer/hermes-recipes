# Hermes Wingtips #111: name the skill, then call it

posted 2026-10-26. original: [https://x.com/witcheer/status/2114650743500382473](https://x.com/witcheer/status/2114650743500382473)

when you and your agent finish a task you will do again, ask it to keep the steps as a skill:

`save what we did as a skill called weekly-update`

it writes the steps from the chat you had and saves them. the name you pick becomes a slash command, so in a new chat you type /weekly-update with your notes and it follows the same steps.

great for a weekly update, a report you format the same way every time or a setup you repeat on each new project!

docs: [https://hermes-agent.nousresearch.com/docs/guides/tips#when-to-create-skills](https://hermes-agent.nousresearch.com/docs/guides/tips#when-to-create-skills)
