# Hermes Wingtips #91: files in your Telegram chat, ask for a PDF and it arrives as an attachment

posted 2026-10-04. original: [https://x.com/witcheer/status/2106632278839337357](https://x.com/witcheer/status/2106632278839337357)

your Hermes Agent can send you files on Telegram, not only text.

want something you can read later on your phone, or forward to someone?

ask for the format in your message:

"send me that as a PDF"

Hermes makes the file and it arrives in the chat as an attachment.

it works for a chart too, which comes through as an image, or a table as a spreadsheet!

want it every time? add a line to your `~/.hermes/SOUL.md` asking for files over long text replies in chat.

docs: [https://hermes-agent.nousresearch.com/docs/user-guide/features/deliverable-mode](https://hermes-agent.nousresearch.com/docs/user-guide/features/deliverable-mode)
