# Hermes Wingtips #95: let your agent keep checking for you

posted 2026-10-08. original: [https://x.com/witcheer/status/2108082465923649911](https://x.com/witcheer/status/2108082465923649911)

your Hermes Agent can run the same prompt again every few minutes, inside the chat you're already in.

type /loop, how often, then what it should check:

`/loop 5m check build.log and tell me when the build is done`

handy while a build or a deploy is running!

docs: [https://hermes-agent.nousresearch.com/docs/user-guide/features/loops](https://hermes-agent.nousresearch.com/docs/user-guide/features/loops)
