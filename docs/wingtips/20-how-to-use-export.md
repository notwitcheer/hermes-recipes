Hermes Wingtips #20: how to use export

Hermes sessions export is one command for every format. pick with --format:

(1) md or qmd for a readable archive (one file per session and a manifest under `~/.hermes/session-exports`)

(2) html for a self-contained page you can open and share

add `--redact` when anything leaves the box: it hides API keys, tokens and credentials from the write.

for one particular session: `--session-id <id>`.
