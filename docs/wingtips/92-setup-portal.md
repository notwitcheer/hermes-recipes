# Hermes Wingtips #92: Nous Portal in one command

posted 2026-10-05. original: [https://x.com/witcheer/status/2106998344337731926](https://x.com/witcheer/status/2106998344337731926)

on a fresh install, this one command logs your Hermes Agent in to Nous Portal and sets Nous as your provider. it turns on the Tool Gateway too:

`hermes setup --portal`

your browser opens for the login and you pick a model. then you're back in the terminal, ready to chat.

with any paid Nous Portal plan, that same login gives your agent web search, image generation, text-to-speech and a cloud browser, without one extra API key to set up!

to see what got switched on, run `hermes portal info`.

docs: [https://hermes-agent.nousresearch.com/docs/integrations/nous-portal](https://hermes-agent.nousresearch.com/docs/integrations/nous-portal)
